# 当前开发文档导航

本级只收录当前开发需要的有效文档与目录入口。按任务进入相关目录，再阅读其 AGENTS.md 指向的具体文档。

- [项目设计意图](./intend.md)：项目目标、核心体验与长期原则。
- [技术决策](./decisions/AGENTS.md)：当前有效的技术选型与架构决策。
- [开发环境](./development/AGENTS.md)：项目初始化、运行与验证方式。
- [设计参考](./refs/AGENTS.md)：当前仍有参考价值的网站与源码。

新增导航时遵循以下规则：

- 使用渐进式导航，具体条目由所属目录的 AGENTS.md 维护。
- 只列出已经存在且服务当前开发的内容，避免重复条目和空目录入口。
- 历史文档、阶段汇报、工作记录和已废弃文档不列入本级导航；归档后由下级 AGENTS.md 按需索引。
- 当前实现以项目意图、已确认决策及有效规范为依据，历史建议不自动成为需求。
