# TUI 页面与输入呈现

状态：项目所有者已确认本规范及终端输入规范。规范确认不代表推送或部署授权，后者需另行获得项目所有者批准。

## 设计目标

页面整体呈现为终端内的文本界面：等宽字、直角细线边框、路径标签、方括号操作和反色高亮。终端输入紧随输出，不呈现独立表单框。保留原有深色与绿色配色、内容结构及命令能力，不模拟真实 Shell。

## 页面结构

- 顶部会话栏显示主页标识与联系入口。
- 标题使用可选择的纯文本字符画展示「zhu chen」，无图片、外部字体或生成依赖。辅助技术读取语义标题，跳过字符画的逐字符朗读。
- 目录导航显示编号、英文目录与中文名称；编号用于识别，不表示数字快捷键。点击原生锚点定位内容并更新 URL，目标目录与面板反色或边框高亮。
- 终端使用带路径标题的直角面板。原生编辑器无边框、无独立背景，位于 xterm 当前光标行；空输入显示块状光标，聚焦后提供反馈。输入、输出、清屏和滚动行为见终端命令规范。
- 终端下方以方括号菜单提供执行、帮助、目录、返回、清屏；保留语义按钮和键盘焦点，不自动弹出移动端键盘。
- 三个内容目录（关于我、项目与论文、联系与链接）以文件面板展示。项目与论文共用 projects 入口、内容面板和终端目录。标题嵌入边框，标注 README.txt，与命令共用真实内容。尚未补全的资料明确显示整理中。
- 底部状态栏提供主页标识和返回终端的原生锚点。

## 字体

页面文字、字符画、按钮、命令输入及 xterm 输出共用同一套终端等宽字体，统一由全局 --font-terminal 定义，终端读取继承后的字体配置。

优先使用 [Ubuntu Mono](https://design.ubuntu.com/font)，依次回退到 Cascadia Mono、SFMono-Regular、Menlo、Consolas、Liberation Mono、DejaVu Sans Mono。中文优先使用 Noto Sans Mono CJK SC，再回退到 Sarasa Mono SC 和系统 monospace。仅使用访客设备已有字体，不引入字体文件或第三方字体请求；实际字体取决于设备安装情况。

关闭连字和字偶距调整，保持字符独立排列与字符画对齐。中文使用全角字形，英文、数字与标点使用等宽字符。

## 响应式与可访问性

桌面端三个目录横排、内容双列，末尾单独的内容面板跨整行；窄屏目录两列，第三个目录跨整行，内容单列。字符画保持完整、按视口缩小，页面无横向溢出。命令输入保持 16px 字号，长命令在输入行内滚动。

主要入口支持鼠标、触摸与 Tab 导航，不要求命令知识。保留原生链接、文本选择、浏览器快捷键及正常页面滚动；按钮和主要导航具备至少 44px 的触控高度。减少动态效果偏好下光标不闪烁。

关闭 JavaScript 时仍显示字符画、全部静态内容及目录链接，只隐藏交互终端控件并保留欢迎文本。

## 验证

使用现有构建与 Playwright 验证：提示符跟随输出与清屏、命令和历史、中文组合输入、滚动记录、窗口尺寸变化、桌面与移动布局、无脚本内容，以及控制台错误。截图用于确认整体视觉与字符画可读性。模拟移动设备与组合事件不代替真实手机输入法验收。
