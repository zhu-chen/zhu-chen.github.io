# 终端基本命令

## 范围

提供 ls、cd、help、pwd、cat、clear、whoami、history 八个命令，用于浏览主页内容。命令只作用于预定义的内容目录，没有真实 Shell、主机文件访问或写入能力。

当前内容目录为 about、projects、publications、contact，每个目录包含 README.txt；根目录也有一份浏览说明 README.txt。~ 和 / 都表示主页根目录，首次打开时位于根目录。个人信息尚未补全的部分明确显示“整理中”，不提供虚构履历。

页面静态内容和命令内容共用 src/data/homepage.ts；新增真实内容时从这里维护。页面上的普通锚点与链接始终可用，访客无需输入命令；关闭 JavaScript 时仍可阅读全部已发布内容。

## 命令

| 命令 | 行为 |
| --- | --- |
| help [命令] | 列出可用命令，或解释指定命令的用法。每个命令也支持 --help。 |
| ls [路径] | 默认列出当前目录，目录名称带 /；指定文件时显示其名称。暂不支持 -l、-a 等选项。 |
| cd [目录] | 切换当前内容目录；无参数或 ~ 回到根目录，.. 返回上级，- 返回上一次成功所在目录。 |
| pwd | 显示当前绝对路径，例如 /about。 |
| cat <文件> | 阅读单个内容文件，例如 cat ~/about/README.txt。 |
| whoami | 显示主页主人的简介，与 about/README.txt 内容一致。 |
| history | 显示本次访问最近 50 条非空、长度有效的命令，包含本次 history；编号从 1 开始。 |
| clear | 清空终端输出和滚动记录，保留当前目录和命令历史。 |

路径大小写敏感，支持绝对路径、相对路径、~、.、.. 和重复斜线。在根目录继续向上仍停留在根目录。路径中的每一级必须存在且可进入，不能通过 missing/.. 或 README.txt/.. 绕过验证。路径错误、文件与目录类型不符、未知命令或参数数量错误会给出提示，并保留当前目录。

当前路径不含空格，不实现引号解析、通配符、变量替换、管道、重定向或多命令执行。输入只按空白分词，并且仅调度上述固定命令。

## 输入和输出

- xterm.js 展示命令回显和结果；终端底部的原生文本框负责输入，支持正常编辑、选择、复制、粘贴与中文输入法。
- Enter 或“执行”按钮提交命令；空白输入无操作。命令长度最多 256 个字符。粘贴不会自动执行。
- 输入法组合期间不提交命令、不切换历史；Tab 保留原生焦点导航。浏览器快捷键保持正常，不自动聚焦输入框或弹出手机键盘。
- ↑ / ↓ 浏览命令历史；返回历史末尾时恢复进入历史前的草稿。历史仅保留在内存，刷新后清空。
- 快捷按钮可查看帮助、列出目录、回到根目录或清屏。提示符显示当前位置。
- 终端保留最多 500 行滚动记录；用户输入中的控制字符不能作为终端控制序列执行。
- 终端未就绪时隐藏输入控件，保留欢迎文本和静态内容。

示例流程：ls → cd about → ls → cat README.txt → cd .. → pwd。

## 验证

使用现有 Playwright 测试运行器检查命令行为与浏览器交互。重点覆盖目录切换及错误恢复、帮助与内容、清屏与历史、输入法组合事件、常规焦点导航，以及桌面/移动视口和关闭 JavaScript 的基本访问。模拟输入法事件和移动设备不替代真实手机及中文输入法验收。
